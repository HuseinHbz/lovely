## ۱. دامنه‌ی پروژه

یک وب‌اپلیکیشن داستان تعاملی ۲۰ مرحله‌ای به زبان فارسی و راست‌به‌چپ، خصوصی و پشت توکن، که روی یک سرور Ubuntu مستقر می‌شود. محتوای داستان در `docs/STORY.md` و برنامه‌ی اجرا در `docs/PHASE-PLAN.md` است.

> **چرا Next 15 و نه 16؟** سند فازبندی Next.js 15 را «قطعی‌شده» اعلام کرده. نسخه‌ی ۱۶ منتشر شده ولی تصمیم سند تغییر نکرده، پس روی آخرین ۱۵ ماندیم (`15.5.22`). همین برای TypeScript: نسخه‌ی ۷ منتشر شده، ولی ۵٫۹ با اکوسیستم Next 15 آزموده‌تر است.

> **دیتابیس ندارد.** طبق قاعده ۲ چیزی برای ذخیره نیست. PostgreSQL و Prisma از MVP حذف شده‌اند.

### سخت‌گیری‌های TypeScript فراتر از `strict`

`noUncheckedIndexedAccess`، `exactOptionalPropertyTypes`، `noImplicitOverride`، `noUnusedLocals`، `noUnusedParameters`، `noFallthroughCasesInSwitch`، `verbatimModuleSyntax`. اولی مهم‌ترین است: دسترسی به `stages[i]` را `Stage | undefined` می‌کند و موتور داستان را وادار می‌کند مرحله‌ی ناموجود را واقعاً هندل کند.

## ۴. ساختار مخزن

مخزن روی گیت‌هاب `lovely` نام دارد ولی ساختار داخلی همان چیزی است که سند می‌خواهد و در ریشه پیاده شده — زیرپوشه‌ی `wolf-and-hedgehog/` ساخته نشد.

```
.
├── app/
│   ├── globals.css        # @font-face + توکن‌ها + پایه
│   ├── layout.tsx         # dir="rtl" lang="fa" + noindex
│   └── page.tsx           # از فاز ۵ فقط ریدایرکت به /story
├── docs/                  # مستند هر فاز + STORY.md + PHASE-PLAN.md
├── public/fonts/          # فونت‌های self-host + مجوزها
├── .env.example
├── eslint.config.mjs
├── next.config.ts
├── postcss.config.mjs
└── tsconfig.json
```

پوشه‌های `components/`، `content/`، `lib/`، `public/art/`، `scripts/` و `deploy/` در فازهای بعدی ساخته می‌شوند — پوشه‌ی خالی commit نمی‌کنیم.

## ۵. فونت‌ها

هر سه فونت باید self-host باشند چون سایت روی سرور ایران بالا می‌آید و نباید به CDN خارجی وابسته باشد.

| فونت                | نقش                         | وضعیت                                                             |
| ------------------- | --------------------------- | ----------------------------------------------------------------- |
| استعداد (Estedad)   | متن اصلی                    | ✅ نصب شد، نسخه‌ی variable، دو زیرمجموعه (عربی ۵۷KB + لاتین ۲۷KB) |
| وزیرمتن (Vazirmatn) | برچسب، شماره‌ی پرونده، فوتر | ✅ نصب شد، وزن ۴۰۰ (۵۰KB)                                         |
| مربا (Morabba) Bold | تیتر، عنوان مرحله، متن مُهر | ⚠️ **پیدا نشد**                                                   |

**مربا از هیچ منبع آزادی در دسترس این سرور پیدا نشد** — نه npm، نه گوگل‌فونت، نه مخزن عمومی. بلوک `@font-face` مربوط به آن در `globals.css` کامنت است تا مرورگر درخواست ۴۰۴ نزند، و `--font-display` فعلاً روی استعداد سنگین برمی‌گردد. برای فعال کردنش `public/fonts/README.md` را ببین. **این تنها چیزی است که در فاز ۰ ناتمام ماند و به ورودی انسانی نیاز دارد.**

جمع payload فونت‌ها: حدود ۱۳۵ کیلوبایت.

## ۶. توکن‌های طراحی

پالت بخش ۳٫۱ سند به‌صورت `@theme` در `app/globals.css` تعریف شد و Tailwind از رویشان utility می‌سازد (`bg-shab`، `text-mahtab`، `text-tigh`، …). مقیاس تایپ `12/14/16/20/26/34/48` روی `--text-*` سوار شد. جزئیات و تست کنتراست در `docs/01-design-system.md` (فاز ۱).

قاعده‌ی سفت: **هیچ رنگ hex ای خارج از `globals.css` نوشته نمی‌شود.**

## ۷. دستورها

| دستور            | کار                  |
| ---------------- | -------------------- |
| `pnpm dev`       | سرور توسعه           |
| `pnpm build`     | build تولیدی         |
| `pnpm start`     | اجرای build          |
| `pnpm typecheck` | `tsc --noEmit`       |
| `pnpm lint`      | ESLint               |
| `pnpm format`    | Prettier روی کل مخزن |

از فاز ۵:

| دستور                | کار                                                                |
| -------------------- | ------------------------------------------------------------------ |
| `pnpm check`         | typecheck + lint + کنتراست + اعتبارسنجی محتوا + بازبینی حریم خصوصی |
| `pnpm audit:privacy` | پنج بررسی حریم خصوصی                                               |
| `pnpm drafts:list`   | فهرست گزینه‌های تأییدنشده                                          |
| `pnpm drafts:check`  | همان، فقط کد خروج                                                  |

pre-commit هوک `lint-staged` و بعد `typecheck` را اجرا می‌کند. `prebuild` نگهبان پیش‌نویس و بازبینی حریم خصوصی را اجرا می‌کند — یعنی build تولیدی با گزینه‌ی تأییدنشده یا با یک `fetch` خارجی تازه، می‌شکند.
