# پیش‌نویس واکنش‌ها — منتظر تأیید

**وضعیت:** ۳۳ مورد، هیچ‌کدام تأیید نشده.

`docs/STORY.md` برای بیشتر مراحل فقط واکنش گزینه‌ی داستانی را نوشته بود. بقیه‌ی گزینه‌ها واکنش ندارند و طبق قاعده‌ی سند «گزینه‌ی بی‌واکنش یعنی گزینه‌ی تنبیهی» — zod هم بدون آن build را می‌شکند.

این‌ها پیش‌نویس من‌اند. **هیچ‌کدام هنوز محتوای پروژه نیستند.** هرکدام که وارد `content/stages/` می‌شود با `draft: true` علامت می‌خورد و `pnpm validate:content:strict` تا تأیید نشدنش با کد خطا تمام می‌شود.

## قواعد نگارشی که رعایت شده

- **شوخی به گرگ برمی‌گردد، نه به جوجه‌تیغی.** گرگ سوژه‌ی طنز است.
- **هیچ گزینه‌ای غلط اعلام نمی‌شود.** بدترین حالت مُهر «مشکوک» و یک جمله‌ی خنده‌دار است.
- **لحن پرونده حفظ شده:** صدای سیستم اداری و خشک، محتوای بامزه.
- ارجاع متقابل بین مراحل (مثلاً «اوکی» و گل‌سر) عمدی است.

## نحوه‌ی تأیید

برای هر مورد یکی از سه کار را بکن:

- **تأیید** → `draft: true` برداشته می‌شود.
- **ویرایش** → متن جایگزینت را بده.
- **رد** → خودت متنش را بنویس.

## چیزی که در این پیش‌نویس **نیست**

- **حالت چهره‌ی شخصیت‌ها به‌ازای هر گزینه.** آرت‌ورک چهار حالت دارد (`neutral` / `smug` / `hurt` / `guilty`) ولی اینکه کدام گزینه کدام حالت را بیاورد تصمیم توست. اگر بخواهی، در دور بعد کنار همین جدول‌ها پیشنهاد می‌دهم.
- **متن مُهر برای مراحل ۱ و ۲.** داستان واکنش‌هایشان را کامل دارد ولی مُهر ندارند. واژگان مُهر در سند «ثبت شد / مردود / مشکوک / وکیل خبر شد» است.
- **مراحل ۴، ۹، ۱۰، ۱۲، ۱۳، ۱۴، ۱۷، ۱۹** — این‌ها در داستان واکنش مشترک یا پیام سیستمی کامل دارند و چیزی کم ندارند.
